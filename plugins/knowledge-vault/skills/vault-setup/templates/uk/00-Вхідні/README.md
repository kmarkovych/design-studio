# Вхідні

Сюди — усе сире: чернетки, вставлені шматки, ідеї, скріншоти з нотатками. Раз на тиждень розбирати до нуля за [[Схема-бази]].

Агенти кладуть сюди нотатку лише тоді, коли не знають, куди її віднести, і кажуть про це.
